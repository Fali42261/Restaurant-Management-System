# swapDigit Restaurant Management System

Repository branches:
- `DevUI`: restaurant-management user interface (MAUI).
- `DevApi`: ASP.NET Core Web API using ADO.NET and SQL Server.

Backend setup instructions are in `RestaurantManagement.API/README.md`. Run the database setup script at `RestaurantManagement.API/Database/SwapDigit_Database_Setup.txt` before starting the API.

Keep production credentials out of source control. Use .NET User Secrets locally and environment variables in hosted environments.
